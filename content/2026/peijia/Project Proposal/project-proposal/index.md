# Voice-reactive Web

Making websites react to human voices

1. Project idea

I want to create a system that allows normal websites to react to people's voices, let websites to react to the way people speak.

For example, when someone speaks quickly, the text on the website will shake faster. When the voice gets louder, images and text can become bigger. Changes in the voice can also change the colours and movements on the page.

2. work

Use Arduino as the main physical interaction device.It will have a microphone sensor to capture sound, a knob to adjust how strongly the website reacts, and a button to turn the interaction on and off.

Arduino will send the sound data to the computer. Then JavaScript will use this data to change the website.

I also want to connect RGB LED lights to Arduino. I will put the lights behind the computer screen. 

3. Visual changes 

keep the original design of websites. don't want to change their content or layout. I only want to change how the text and images look and move.

For example:

- Fast speaking can make text shake faster.
- Louder sounds can make images and text grow.
- Different voice tones can change the shape and movement of elements.
- When the person stops speaking, the website slowly returns to normal.

The lights will also change their brightness, colour and speed.

4. Technology 

 plan to use:

- Arduino
- Microphone sensor
- Potentiometer and push button
- RGB LED strip
- JavaScript and CSS
- Serial communication between Arduino and the computer

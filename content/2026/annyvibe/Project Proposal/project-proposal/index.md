# Final Project Proposal – Mini Audio-Visual Performance

Nov 12, 2026 · @Anny

## Concept

I want to make a mini audio-visual performance: a small stage inside a transparent acrylic box, played live with a small controller.

The controller works like an instrument. Each input triggers a visual, so a short piece can be performed live with projection, light etc. I want the result to be playful and visually striking rather than conceptually heavy.

Technically, I want to explore:

- Combining Rapsberry Pi(physical input, lights, motion) with TouchDesigner (real-time visuals) 
- Projecting into a small physical space so that projection and real objects read as one scene.
- Building a small controller that feels like an instrument.

## What it looks like

A transparent acrylic box, roughly 30–40 cm, holds a miniature scene and sits on a base that hides the electronics. The final scene and form are still open.

- **Projection:** a projector outside the box projects TouchDesigner visuals into it, onto surfaces inside the scene.
- **Physical scene:** 3D-printed objects with small embedded LEDs build the environment
- **Controller:** a small separate controller in front of the box, with knobs, buttons and sensors(distance sensor or capacitive sensor).
